# Plant Sequence Analysis with Biostrings

## Overview
This project demonstrates basic DNA sequence analysis using the Biostrings package in R.

## Objectives
- Read FASTA files
- Calculate sequence length
- Determine GC content
- Generate reverse complements
- Translate DNA sequences into proteins
- Perform pairwise sequence alignment

## Files
- analysis.R
- plant_sequences.fasta
- translated_proteins.fasta
- sequence_summary.csv
- README.md

## Tools Used
- R
- Biostrings
- BiocManager

## Key Results
- Two plant gene sequences analyzed
- GC content calculated
- Protein sequences generated
- Sequence alignment performed
